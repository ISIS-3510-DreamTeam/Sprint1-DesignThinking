# Sprint 1 - Design Thinking para Diseño de Aplicaciones

## Objetivo del sprint
Definir una propuesta inicial de aplicación centrada en el usuario mediante el proceso de Design Thinking.

## Duración
- Inicio: Semana 1
- Fin: Semana 2

## Equipo y roles
- Product Owner: Define visión y prioridades.
- Facilitador: Coordina dinámicas de Design Thinking.
- Equipo de diseño/desarrollo: Investiga, ideación y prototipado.

## Fases del sprint
1. **Empatizar**: entrevistas rápidas, mapa de empatía y hallazgos.
2. **Definir**: problema principal y perfil de usuario objetivo.
3. **Idear**: lluvia de ideas y selección de solución.
4. **Prototipar**: wireframe o prototipo de baja fidelidad.
5. **Testear**: validación rápida con usuarios y aprendizajes.

## Backlog del sprint
- [ ] Levantar al menos 3 necesidades de usuarios.
- [ ] Redactar una declaración de problema clara.
- [ ] Generar mínimo 10 ideas de solución.
- [ ] Crear un prototipo navegable básico.
- [ ] Ejecutar 3 pruebas de usabilidad.

## Entregables
- Resumen de investigación de usuarios.
- Definición del problema.
- Propuesta de solución seleccionada.
- Prototipo inicial.
- Resultados de pruebas y mejoras sugeridas.
